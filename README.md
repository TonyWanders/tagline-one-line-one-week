A program that writes one one-line tagline for make.fun to
`/output/entry.txt`, for the make.fun competition
[One Line, One Week: The make.fun Tagline](https://make.fun/bounty/u-boge-one-line-one-week-the-make-fun-tagline-66aca584).

## Run it

```sh
python3 main.py
```

It writes the tagline below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The tagline is 50 characters, inside the 1 to 100 gate, and
exactly one line.

## The tagline

```
Agents build. The best win. make.fun pays in USDC.
```
